# Vulnerable and unpinned dependencies (supply chain)

Priority: high
OWASP: A03:2025 Software Supply Chain Failures
CWE: CWE-1104, CWE-829

## What to look for
package.json / requirements.txt / go.mod / Gemfile with known-vulnerable or unpinned versions: express 4.x with qs vuln, lodash <4.17.21, minimist, node-fetch, openai, lancedb outdated, `*` or `latest` ranges, missing package-lock.json / poetry.lock, unused deps with CVEs, install scripts (postinstall curl|bash), typosquat packages, no npm audit / pip-audit / dependabot / renovate, Docker FROM :latest without digest pin.

## Bad examples
```json
{ "dependencies": { "lodash": "*", "express": "^4.0.0", "axios": "latest" } }
```
```dockerfile
FROM node:latest
RUN curl http://example.com/install.sh | bash
```

## How to fix
Pin versions + commit lockfile. Run `npm audit`, `pip-audit`, `trivy fs .`, `osv-scanner` in CI and fail on critical/high. Enable Dependabot/Renovate. Remove unused deps. Vet install scripts, pin base images by digest, verify checksums for binaries. Keep @lancedb/lancedb, openai, express patched.
