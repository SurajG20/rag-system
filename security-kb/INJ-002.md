# Command injection and unsafe shell execution

Priority: high
OWASP: A05:2025 Injection
CWE: CWE-78, CWE-88

## What to look for
child_process exec, execSync, spawn with shell:true, system(), popen(), Runtime.exec(), os.system, subprocess with shell=True, backticks, `eval` of shell strings, unquoted interpolation into shell commands using req.query, req.body, req.params, headers, filenames: `exec("convert " + userFile)`, `execSync(`git clone ${url}`)`, `spawn(cmd, {shell:true})`, Python `os.system(f"ping {host}")`, `subprocess.call(user_input, shell=True)`.

## Bad examples
```js
const { exec } = require("child_process");
exec("ffmpeg -i " + req.body.file);
execSync(`nslookup ${req.query.host}`);
```

## How to fix
Avoid the shell. Use execFile/spawn with args array: `execFile("ffmpeg", ["-i", file])`. Validate and allowlist inputs (alphanumeric, enum, path basename). No shell metachars. If shell is required, escape with shlex.quote / shell-quote and run with least privilege.
