# Cross-site scripting (XSS) and unsafe HTML rendering

Priority: high
OWASP: A05:2025 Injection
CWE: CWE-79, CWE-116

## What to look for
innerHTML, outerHTML, document.write, document.writeln, unescaped template output, res.send of user input, dangerouslySetInnerHTML, v-html, {{{triple-mustache}}}, |safe filter, jQuery .html(userInput), EJS <%- user %>, Handlebars triple-stash, Pug `!{user}`, React dangerouslySetInnerHTML without DOMPurify, reflected `req.query` echoed into HTML, stored user content rendered as HTML.

## Bad examples
```js
el.innerHTML = req.query.q;
res.send("<div>" + req.body.comment + "</div>");
<div dangerouslySetInnerHTML={{__html: userBio}} />
```

## How to fix
Escape output by context (HTML, JS, URL, CSS). Use textContent instead of innerHTML. Use safe templating default-escape (EJS <%= %>, React {}). Sanitize HTML with DOMPurify if markup is required. Set Content-Security-Policy without unsafe-inline.
