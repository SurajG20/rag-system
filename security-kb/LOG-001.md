# Sensitive data exposure and unsafe logging

Priority: high
OWASP: A09:2025 Security Logging and Alerting Failures, A04:2025 Cryptographic Failures
CWE: CWE-532, CWE-200, CWE-117

## What to look for
console.log of passwords, tokens, API keys, PII, req.body, req.headers.authorization, OpenAI prompts/completions with user data, vector-db chunks with private docs logged, `console.error(err)` leaking connection strings, log injection (`log(req.query.name)` without sanitization), audit gaps: login, password reset, /scan, /kb/reindex with no audit record, logs without timestamp/user/action/outcome, PII stored unencrypted in LanceDB /tmp clones.

## Bad examples
```js
console.log("login", req.body);
console.log("OPENAI key", process.env.OPENAI_API_KEY);
logger.info(`scan ${req.body.url} by ${req.query.user}`);
```

## How to fix
Never log passwords, tokens, keys, PII. Redact: `redact(req.body, ["password","token","apiKey"])`. Sanitize log lines (strip \r\n). Log security events with user, timestamp, action, outcome, IP. Sync time via NTP. Set LanceDB /tmp retention + access controls, encrypt sensitive fields at rest. Alert on repeated auth failures and authz denials.
